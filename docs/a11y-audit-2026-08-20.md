### 弱化文字 FAIL 的处理结论

亮色下 `neutral-400`（2.56:1）仅用于**非关键辅助信息**（占位符、时间戳、装饰分隔符、版本号）。
- 占位符内容有对应 label，WCAG 豁免；
- 表单提示文字（`Field` hint）已在本轮提升为 `neutral-500`（4.75:1，达标）；
- 其余装饰性弱化文字记录为「已知缺口」，MASTER.md §10.2 登记豁免，后续迭代逐步收敛到 neutral-500。

## 3. 焦点可见（WCAG 2.4.7）

- 基础组件（Button/Input/Alert）：已有 `focus-visible:ring-2` + ring-offset，随主题自适应；
- **本轮新增**：ResultView 全部内嵌按钮（AI 改写/优化/弹窗/推荐卡/补位计划）、ErrorBoundary 重试、KeywordChip、ImportDialog、CareerModelChart 图表重试按钮补齐焦点环；
- **本轮新增全局兜底**：globals.css 对未写焦点样式的裸按钮/switch/链接统一 `outline: 2px solid primary-500`，杜绝键盘焦点不可见。

## 4. 语义与 ARIA（WCAG 1.3.1 / 4.1.2）

| 项 | 结论 |
|---|---|
| 文档结构 | ✅ 仅首页唯一 H1；卡片用 h2/h3 |
| 弹窗 | ✅ `role="dialog"` + `aria-modal` + `aria-labelledby`（+`aria-describedby`） |
| 错误提示 | ✅ `Alert danger` 用 `role="alert"`（打断播报），其余 `role="status"` |

## 5. 动效（WCAG 2.3.3）

- **本轮新增**：globals.css 增加 `@media (prefers-reduced-motion: reduce)` 块——弹窗入场动画关闭、全站 transition/animation 瞬时化。
- 全站仅 3 处动效（隐私弹窗 2 个 + 进度条过渡 + 按钮 active 缩放），均 < 300ms。
